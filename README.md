# 📊 Supermart Grocery Sales Dashboard

## 📌 Project Overview
The Supermart Grocery Sales Dashboard is a data analytics project
designed to analyze grocery sales performance, profitability, and
business trends using a retail sales dataset.

The project transforms raw sales data into meaningful insights
through interactive visualizations, KPI metrics, and category-wise
and regional analysis.

## 🎯 Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories and subcategories.
- Understand regional and state-wise sales distribution.
- Track monthly sales trends.
- Analyze the relationship between discounts and profitability.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Cleaning and Analysis
- Pivot Tables and Pivot Charts
- KPI Cards
- Interactive Dashboard
- HTML and JavaScript (for the interactive version)

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Average Discount

## 📊 Dashboard Features
- Sales by Product Category
- Monthly Sales Trend
- Profit by Region
- Top 10 Subcategories by Sales
- Profit by Discount Band
- Top States by Sales
- Interactive Filters for Category, Region, State, and Year

## 💡 Business Insights
This dashboard helps identify sales trends, evaluate product
performance, compare regional profitability, and understand
discount-related business performance.

## 📂 Project Files
- `Dashboard.xlsx` – Excel dashboard and analysis
- `Dashboard.html` – Interactive dashboard
- `Dataset.csv` – Raw grocery sales dataset
